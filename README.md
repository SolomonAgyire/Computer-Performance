# Computer Performance Analysis

This project uses a Python script and a Random Forest model to evaluate the performance of a laptop or PC. The tool collects system metrics and predicts overall performance. It works seamlessly on both Windows and macOS.

## Features

- Collects real-time system metrics.
- Predicts performance using a Random Forest model.
- Cross-platform support: Windows and macOS.

## Requirements

Install the required dependencies using:

```bash
pip install -r Requirements.txt
```

## Usage

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Computer-Performance-main
   ```
2. Run the script:
   ```bash
   python SCRIPT.py
   ```

The script will gather system metrics and evaluate performance based on the Random Forest model.
